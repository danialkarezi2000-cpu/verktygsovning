# Verktygsövning

Det här projektet är en övning där jag lär mig att använda terminalen, Visual Studio code, Git och GitHub.
I övningen skaper jag mappar och filer och lär mig grunderna i versionshantering.

## Git -kommandon

`git init' - skapr ett Git -repository.
'git status' - visar vilka filer som har ändrats och vad Git känner till.
'git add' - lägger till ändringar inför nästa commit.
'git commit -m "meddelande"' - sparar en verison i Git-historiken.
'git log' - visar tidigare commits.
'git remote' - hanterar kopplingen till ett repositiry på GitHub.
'git branch' - används för att hantra branches.
'git push' - skickar commits till GitHub.
'git pull' - hämtar ändringar från GitHub.

## Grundläggande Git -begrepp

### Repository

Ett repository är en plats där projektets filer och versionshistorik sparas.

### comit

En commit är en sparad verion av projektet. Den visar vilken ändringar som har gjort.

### Versionshistorik

Versionshistoriken visar hur projektet har förändrats över tid och vilka commits som har gjorts.
